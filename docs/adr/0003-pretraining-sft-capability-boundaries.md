# ADR-0003：预训练、SFT与能力目标的职责边界

- 状态：已决定
- 日期：2026-08-29
- 决策人：项目用户
- 范围：1488万参数《斗破苍穹》模型的训练、评测与后续产品能力

## 决策

本项目明确区分三类问题：**预训练负责什么、SFT能补什么、哪些能力不该追求。** 后续数据配比、训练停止条件、评测结论和视频介绍均以此边界为准，不能用一种训练阶段的指标代替另一种能力验收。

### 预训练负责什么

预训练通过预测下一个Token学习语料的语言分布，主要负责：

1. 中文句法、词语搭配、段落与对话结构。
2. 《斗破苍穹》的叙事语气、常见人物、术语及其共现关系。
3. 根据已有上下文继续生成小说文本的基础能力。
4. 为后续SFT提供可塑的语言模型权重。

预训练Loss或验证BPC下降，只能证明下一Token预测改善，不能直接证明模型会聊天、会遵循指令、会正确回答事实或会承认未知。预训练验收必须同时查看验证BPC、固定续写、重复退化和人工流畅度。

### SFT能补什么

SFT通过“用户输入→理想回答”的监督样本，把预训练模型从续写器调整为有限的助手，主要负责：

1. 识别问题、聊天和任务指令，并按要求直接作答。
2. 学习回答长度、格式、语气、EOS停止和多轮角色结构。
3. 强化核心人物身份、已核验小说事实、纠错和有证据的未知边界。
4. 学习基于给定材料提取、概括和组织答案。

SFT不能凭空创造底座、训练数据和上下文窗口中不存在的稳定能力。SFT Loss下降也不能单独证明事实正确、语义相关或对未见问题具有泛化能力；必须使用分类评测、密封测试和人工抽查。

### 哪些能力不该追求

在“单本小说、1488万参数、Context 512”的条件下，不把以下目标作为纯参数模型的验收要求：

1. 不把模型宣传或训练成通用ChatGPT，不追求覆盖开放世界知识。
2. 不补数学题，不把算术能力作为本项目目标。
3. 不要求模型知道实时天气、时间、店铺或联网信息；它应说明边界并索取必要上下文。
4. 不要求模型仅靠参数精确记住全书每章、首次出现、全局计数和复杂关系链；这些任务交给章节/实体检索与索引。
5. 不鼓励在证据不足时猜测，也不以死记长篇原文作为质量提升。
6. 不用总Loss、单个漂亮样本或机械Harness的`PASS`代替语义验收。

## 后续执行规则

- 预训练模型负责语言组织和小说续写底座；SFT负责交互行为与有限任务映射；检索负责可核验的全书细节。
- SFT数据优先投入自然对话、指令遵循、核心人物、材料问答、纠错和能力边界，不再加入数学任务。
- 模型回答全书细节时，应基于检索证据；无法确认时明确说明，而不是猜测。
- 选择checkpoint时同时查看验证指标、EOS、分类行为、固定样本和人工评审；密封测试只在冻结候选上使用。
- 视频材料必须准确说明该模型的目标是“单本小说领域的教学型小语言模型”，而不是通用大模型。

## 后果

该决策缩小了能力范围，但使训练资源、数据治理和评测标准更一致。项目成功不再定义为“什么都会”，而定义为：模型能生成较像样的小说文本，能完成有限自然对话与指令，在给定证据时正确处理小说问题，并对实时信息和未核验事实保持诚实边界。

## 验证状态

M019已经按该边界完成纯预训练审计：Step 5750通过最低小说语言基座门，Step 5750到6000进入当前配置下的实用平台期；test仍封存。结果没有把聊天、开放世界知识或自由问答设为预训练硬门，也没有把validation人物候选排序解释为可靠知识问答。完整证据见`reports/milestones/019_pretrain_capability_audit/README.md`。
