# ADR-0001：单本小说条件下的最大效果路线

- 状态：已决定
- 日期：2026-08-28
- 范围：《斗破苍穹》固定预训练语料、本机 Apple M4 16GB、8105025 参数模型

## 背景

正式 v4 语料共有 6,120,275 个字符。BPE 后，训练集为 3,416,400 Token，验证集为 195,068 Token，测试集为 184,808 Token；模型采用 256 维 Embedding、8 层、8 头、FFN 1024、Context 512，共 8,105,025 个参数。

累计 6000 步预训练约产生 24,576,000 个训练 Token 曝光，相当于反复浏览训练语料约 7.2 次。最后一个评估点的验证 Loss 仍降到 4.7759，独立 Test Loss 为 4.7476，但固定续写仍有重复、语法和情节跳跃。这说明模型尚有可学习空间，同时已经明显受限于单本小说的数据多样性。

SFT 的目标与预训练不同：预训练学习续写，SFT 学习按问题作答。M013 的已知人物过度拒答不是“小说里没有知识”，而是 SFT 的未知拒答样本太强、核心人物样本太弱，并且旧采样器没有保证所有训练记录和核心事实获得稳定曝光。

## 决策

保留当前约 810 万参数结构，不继续放大参数。采用“受控续预训练 + 分层 SFT + 检索增强”的三段式路线：

1. 从 M007 纯预训练最佳检查点继续低学习率预训练，而不是从 SFT 模型倒回去续写训练。
2. 每次新的预训练模型都从同一冻结 SFT 数据重新微调，SFT 不与预训练来回交替。
3. 把核心人物、扩展人物、通用能力和有证据的未知实体分池采样；模型选择同时看完整验证 Loss、分类行为和 EOS。
4. 对章节、首次出现、关系链和细节问答增加实体/章节检索。参数模型负责理解问题和组织回答，检索层负责提供准确原文证据。

## 为什么不扩大模型

单本小说只有约 341.6 万个唯一训练 Token。增加层数或 Embedding 会增加记忆容量，却不会增加语言现象、世界知识和问答示例；结果更可能是训练集记忆、更慢训练和更严重过拟合，而不是更稳定聊天。当前 810 万参数已经处在本项目可接受上沿。

若只追求单位数据的预训练效率，300 万至 500 万参数可能更匹配这份语料；但当前 810 万模型已经形成完整实验链路，且能承载后续 SFT，所以保留它比重新缩小模型更有价值。只有在加入更多已授权中文语料后，才重新评估 1500 万至 3000 万参数。

## 执行顺序和停止条件

### A. 当前实体修复

- 使用 v5.2.2 的 4516 条数据：3479 train、495 val、542 test。
- 采样比例固定为通用回放 45%、核心实体 35%、扩展实体/关系 15%、有证据未知 5%。
- 当前 1000 步实验已完成。最新版公开人物题 4/5，隐藏实体题 19/20，EOS 20/20；“萧炎是谁”和“药尘是谁”已经正确。
- 隐藏题已经使用，后续若继续调实体数据，必须冻结一套新的未见评估题，不能反复对这 20 题调参。

### B. 续预训练

- 从 `runs/pretrain_v4_m4_continue6000/best.pt` 开始，不从任何 SFT checkpoint 开始。
- 学习率上限 `1e-5`，先增加 3000 步；每 250 步评估一次完整/固定验证口径。
- 连续 3 个评估点验证 Loss 改善小于 0.01，或重复/乱码门槛恶化，则停止；仍稳定改善时最多再增加 3000 步。
- 重新保存固定小说续写、重复率、Distinct-2/3、EOS、人工流畅度和事实一致性结果。不能只用 Loss 验收。

### C. 重新 SFT

- 新预训练 checkpoint 必须从头运行 v5.2.2 SFT；不能把当前 SFT optimizer 状态接到新预训练模型。
- 先 100 步安全试跑，再 1000 步正式训练；公开分类评估选 checkpoint，新的隐藏集只在冻结候选上使用一次。
- 若总行为仍低于 18/30，不盲目堆 Step；按失败类别补数据或承认 810 万参数和现有通用数据的能力边界。

### D. 检索增强

- 建立章节索引、实体别名表和可引用证据块，评估 `Recall@k`。
- 回答小说事实前检索相关段落，把最多 2 至 4 个证据块放入 Context 512。
- 对“资料里没有”的判断只在检索覆盖充分时触发，避免再次把已知人物错误路由为未知。

## 可达到的效果上限

纯 810 万参数模型的合理目标是：模仿本书文风做短篇续写、识别主要人物和核心设定、完成有限的自然聊天与短指令。它不应被宣传为通用 ChatGPT，也不能保证记住全书每个章节、首次出现和复杂关系链。

在“只使用这本小说作为固定知识源”的前提下，最高质量产品形态不是继续放大参数，而是“810 万参数模型 + 高质量 SFT + 章节/实体检索”。这能把模型的语言组织能力和全书的可查证事实结合起来，也是对单本小说数据利用率最高、事实幻觉最低的方案。

## 代价与后果

- 保留 810 万参数可复用现有模型、训练器和视频材料，但预训练流畅度的提升会逐渐变小。
- 分层采样显著改善核心实体，却会牺牲一部分通用样本曝光，因此必须持续看 30 题分类评估。
- 检索会增加工程复杂度，但它比单纯扩大模型更适合章节级事实问答。
- 当前隐藏 20 题已在 best/latest 两个 checkpoint 上使用，因此 19/20 是可信的诊断结果，但不再是未来调参的盲测集。
