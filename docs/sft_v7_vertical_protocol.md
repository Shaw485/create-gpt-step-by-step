# 小说垂直 SFT v7 冻结协议

- 状态：训练前冻结
- 里程碑：M020
- 日期：2026-08-29
- 基座：纯预训练 `step_05750.pt`
- 目标：把单本小说语言基座训练成《斗破苍穹》垂直助手，而不是通用聊天模型

## 1. 能力责任边界

| 能力 | 由谁负责 | SFT v7 的处理方式 |
|---|---|---|
| 核心人物、别名、主要关系、核心设定 | 模型参数 | 仅收录经原文证据核验的高价值事实；核心已知问题必须直接回答 |
| 给定片段后的抽取、概括、比较、解释 | 模型参数 + 当前上下文 | 回答必须能由给定证据推出；证据不足或冲突时明确停答 |
| 首次出现、出现次数、精确章节、全书长时间线、长尾多跳关系 | 检索与索引 | SFT 只训练读取检索结果、引用证据和说明不足，不让参数凭空猜 |
| 小说领域自然问答、多轮承接、格式、语气、EOS | SFT | 使用自然、直接、无元话术的领域对话训练 |
| 小说外知识、实时信息、数学 | 不属于本模型的正向能力 | 只保留少量边界样本，不注入正向答案，不用拒答模板淹没领域能力 |

同一边界必须通过三联样本校准：

1. 核心已知事实：直接回答，不误拒。
2. 长尾或全局断言且未给证据：说明需要检索或材料。
3. 同类问题已给有效证据：恢复作答，不继续拒绝。

## 2. 数据规模与冻结配额

总量固定为 10,000 条：`train=8000`、`val=800`、`public_diagnostic=600`、`sealed_test=600`。每个任务维度按 80%/8%/6%/6% 分层切分。

| 任务维度 | 总量 | Train | Val | Public | Sealed |
|---|---:|---:|---:|---:|---:|
| 参数内核心事实与纠错 | 1800 | 1440 | 144 | 108 | 108 |
| 单段给定证据问答 | 3200 | 2560 | 256 | 192 | 192 |
| 多片段 RAG 接口与证据组合 | 1400 | 1120 | 112 | 84 | 84 |
| 垂直自然聊天、多轮与 EOS | 1800 | 1440 | 144 | 108 | 108 |
| 小说摘要、改写、短续写与表达 | 1300 | 1040 | 104 | 78 | 78 |
| 能力边界、澄清与索取证据 | 500 | 400 | 40 | 30 | 30 |

格式、长度和语气要求横向嵌入各维度，不再单独堆积格式模板。至少 1,200 条为真实多轮；证据与 RAG 中必须包含不足、冲突或干扰负例。

## 3. Split 物理隔离

发布目录必须包含四个彼此独立的 JSONL 文件：

- `train.jsonl`
- `val.jsonl`
- `public_diagnostic.jsonl`
- `sealed_test.jsonl`

另存 `manifest.json`，只公开路径、数量、schema、SHA-256 和冻结状态。训练张量只允许包含 train 与 val；公开诊断器只允许打开 public 文件。任何训练、选模、公开评估或常规测试代码不得读取、缓存、序列化或打印 sealed 正文。

`sealed_test.jsonl` 在构建与独立校验后冻结。之后只有显式传入 `--allow-sealed-test` 的一次性最终评估器可以打开它；该评估只输出聚合指标和 case id，不输出问题、答案或证据正文。一次使用后必须标记为 `spent`，不得据此继续调参。

旧 v6 sealed 600 保持原 SHA，不作为 M020 主测试，也不在本阶段读取；它只保留为未来一次性的 legacy 回归集。

## 4. 数据硬门

正式训练前以下 P0 必须全部通过：

- 数学和通用百科正向训练为 0；项目学习问答为 0。
- 元包装、`可以先`、`先先`、审核占位、空回答、角色交替错误为 0。
- 证据不可推出答案、错误实体、错误章节、证据 SHA 不符为 0。
- 不可编码、序列超过 512 Token、assistant-only 标签或 EOS 错误为 0。
- 精确重复、规范化问题重复、非核心 semantic/evidence/chapter 跨 split 泄漏为 0。
- 核心事实跨 split 复用时必须标记 `seen_fact_unseen_wording`，且问法模板不得跨 split。
- sealed 正文不可被训练、编码、公开评估和日志访问。
- 日志不得记录小说正文、完整 prompt、Token、密码、密钥或授权信息。

质量 P1：

- 核心事实卡覆盖 40–60 个核心实体或概念，并全部绑定可复算的原文证据。
- 至少 1,200 条真实多轮；至少 1,000 条 2–4 chunk RAG；证据/RAG 中 15%–20% 为不足、冲突或干扰负例。
- 回答长度以 33–96 BPE Token 为主体，至少 10% 达到 97–160 Token；不靠复制整段原文凑长度。
- 任一固定回答首句占全体不超过 2%；通用完全相同回答最多 5 次。
- public 与 sealed 题面、模板和证据组独立；sealed 正文在冻结后不可见。

## 5. 训练与选择

1. 基线固定为纯预训练 Step 5750；M018 SFT Step 2000 仅作失败对照，不能作为初始化点。
2. 先运行 20 步 smoke，验证前向、Loss、反向传播、梯度、Checkpoint 恢复、日志和 split 隔离。
3. 正式阶段使用 family-balanced sampling。第一阶段强化路由、EOS 和核心问答，第二阶段混入全量证据/RAG/表达任务。
4. `val` 只用于 teacher-forced Loss、数值稳定性和 early stopping；`public_diagnostic` 用于逐任务行为选择。
5. 只有所有任务硬门通过的 checkpoint 才能成为候选；Loss 只作辅助与同分 tie-break。

## 6. 公开行为验收

| 维度 | 冻结门槛 |
|---|---|
| 核心事实 | 实体/事实正确率 ≥80%；别名 ≥85%；核心已知误拒 ≤5%；无依据附加细节 ≤5% |
| 给定证据 | 抽取 EM/F1 ≥90%；自由回答语义正确 ≥80%；证据支持率 ≥90%；不足时正确停答 ≥90% |
| RAG 生成器 | gold bundle 正确率 ≥80%；引用支持 ≥90%；抗干扰 ≥85% |
| 自然交互 | 路由 ≥90%；多轮承接 ≥80%；格式长度遵循 ≥90%；EOS ≥95%；空输出 0；元话术 ≤1%；串任务 ≤5% |
| 小说表达 | AI 辅助流畅度、局部连贯、提示承接均 ≥2.5/5；机械退化 ≤10% |
| 能力边界 | 域外/长尾边界正确 ≥90%；幻觉事实 ≤5%；给证据后恢复作答 ≥85% |
| 预训练能力保留 | 固定 16 续写非空；机械退化 ≤25%；AI 流畅/连贯不低于 2/5；validation BPC 恶化不超过 10% |

抽取与固定格式可使用 EM/F1；开放回答不得使用全局 Exact Match 作为主要指标。最终对外发布仍需独立真人抽查，AI 辅助评分不得冒充真人验收。

## 7. 诊断与日志

数据构建、证据校验、编码、训练、公开评估、checkpoint 和编排分别使用独立日志模块；每个模块可通过命令行或环境变量单独设为 `OFF/INFO/DEBUG`。日志为带 UTC 时间和 run id 的轮转 JSONL，生产默认不开 DEBUG。

成功路径记录数量、SHA、配额与聚合指标；失败路径记录操作、case id、错误码和非敏感上下文。禁止记录完整小说正文、完整训练样本或秘密字段。每个工具都必须有成功、失败、敏感信息脱敏和 sealed 不可达测试。

### 7.1 SFT 后预训练能力保持口径

专用评测器为 `evaluate_sft_v7_retention.py`。它只接受 SFT v7 checkpoint、对应 `effective_config.json`、train/val 张量身份、数据清单以及 M019 的 validation 工件；CLI 不提供 pretraining test 或 SFT sealed 输入。Checkpoint 必须同时通过 sidecar、Step 5750 祖先、训练签名、两阶段采样计划、数据 SHA、8000/800 数量和 public/sealed 消耗为 0 的血缘检查。

候选与基座都使用 M019 相同的 60 个等距 validation 窗口。保持门使用的 BPC 定义为“固定窗口平均 Token NLL × 冻结 validation Token 数 ÷ validation 字符数 ÷ ln(2)”；必须同时报告候选值、基座值、绝对增量和相对恶化，且相对恶化不超过 10%。M019 训练历史中的完整 validation BPC 只作单列参考，不与固定窗口候选混算。

同一评测还复用 M019 的 16 条 validation 续写和 12 条 validation-prefix Cloze：16 条必须全部非空，机械退化不超过 25%；EOS、4-gram 和 Cloze 只作诊断。AI 辅助流畅度/局部连贯度以及独立真人复核保持 external pending；自动门通过时仍不得把候选标成可发布模型。

Retention JSON、Markdown、控制台摘要和结构化日志不得发布本机绝对路径。项目内路径递归写成仓库 POSIX 相对路径；项目外工件只写成 `artifact://角色/文件名`，不得暴露用户目录或设备目录结构。

## 8. 决策结论

M019 证明 Step 5750 是可后训练的最低小说语言基座；M018 证明“10,000 条结构合格”并不等于行为合格。M020 的重点不是继续堆总量，而是重建能力所有权、自然答案、证据归因、任务专属评测和 sealed 治理。只有数据门与 20 步 smoke 全部通过后，才允许开始正式 SFT。
