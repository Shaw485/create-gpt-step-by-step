# M002b：SFT 前问答基线

## 目的

使用五道完全隔离的测试题记录模型在 SFT 前的回答。SFT 完成后必须使用相同题目、聊天格式、最大生成长度、Temperature、Top-K 和随机种子复测，才能公平比较行为变化。

## 公平初始化

预训练 checkpoint 的词表为 4478，而 SFT 需要五个特殊 Token。基线模型先扩展到4483个 Token：原有 Embedding、Transformer 和输出层参数逐项原样复制，只有五个新增 Token 对应的 Embedding、输出权重和偏置随机初始化。扩展后保存独立 checkpoint，此时 `sft_steps=0`，没有执行 Loss、反向传播或参数更新。

## 生成设置

- 最多生成30个字符。
- Temperature 为0.8。
- Top-K 为20。
- 基础随机种子为42，每道题依次加一。
- `<EOS>` 可以终止生成；`<BOS>`、`<USER>`、`<ASSISTANT>`、`<PAD>` 禁止作为回答输出。

## 日志

模型扩展、生成和报告输出分别记录到 `logs/sft_baseline_model.log`、`logs/sft_baseline_generation.log` 和 `logs/sft_baseline_output.log`。三个类别可用对应的 `SFT_BASELINE_*_LOG_LEVEL` 环境变量独立设置日志级别或设为 `OFF`；文件最大1 MB并保留3个轮转备份。
