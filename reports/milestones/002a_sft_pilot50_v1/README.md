# M002a：50条 SFT 试验数据

## 结果

在不改动 M002 十六条种子集的前提下，建立独立的五十条试验数据：训练集四十条、验证集五条、测试集五条。所有问题、答案和证据均来自已经获得授权并完成清洗的小说语料。

## 三个集合的作用

- 训练集：参与 Loss、反向传播和参数更新。
- 验证集：计算 Loss，但不执行反向传播，用于选择 checkpoint。
- 测试集：SFT 期间完全隔离，只用于记录训练前后的最终行为变化。

## 数据生成方式

问答由教师模型根据原文生成候选答案，因此属于“蒸馏式 SFT 数据”。每条候选数据必须通过原文行号、证据原文、词表字符、重复问题和跨集合主题泄漏检查。程序能验证证据存在，但语义正确性仍需人工抽查。

## 当前结论

五十条数据用于验证完整 SFT 流程和观察行为变化，不代表最终数据规模。确认训练、验证和测试流程正确后，再分批扩展到二百至五百条。

## 复现与诊断

运行 `./.venv/bin/python prepare_sft_pilot50.py` 可重新执行准备流程。数据读取、证据校验和输出分别写入 `logs/sft_data.log`、`logs/sft_validation.log` 与 `logs/sft_output.log`；对应的 `SFT_DATA_LOG_LEVEL`、`SFT_VALIDATION_LOG_LEVEL`、`SFT_OUTPUT_LOG_LEVEL` 可独立设为 `DEBUG`、`INFO`、`WARNING`、`ERROR` 或 `OFF`。每个日志最大 1 MB，并保留 3 个轮转备份。
