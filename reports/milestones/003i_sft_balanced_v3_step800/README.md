# M003i：平衡版 SFT v3 的800步正式实验

## 结论

平衡数据修复了旧模型把开放问题都回答成类别的强偏置，并让模型学会部分事实核验、明确指令和未知回答。它仍没有获得可靠的事实问答和日常对话泛化能力，不能作为可用聊天助手。

这标志字符级SFT v1教学实验完成：数据分布可以明显改变模型行为，但继续增加Step无法克服字符级、710万参数和知识提取能力的限制。下一阶段转入BPE路线。

## 训练配置

- 800训练、100验证、100测试；测试只在模型选择完成后使用。
- Batch 4、Step 800，约4个epoch。
- 学习率 `1e-4`、Weight Decay `0.01`、梯度裁剪 `1.0`。
- CPU训练、随机种子42、每100步完整验证。
- 从统一SFT前检查点重新开始，不接续旧分类模型或20步试跑。

|---:|---:|---:|
| 0 | 5.6150 | 6.2076 |
| 100 | 1.8685 | 3.6985 |
| 200 | 1.2969 | 3.4854 |
| 300 | 0.9370 | 3.4600 |
| 400 | 0.6500 | **3.4099** |
| 500 | 0.4526 | 3.4307 |
| 600 | 0.3304 | 3.4748 |
| 700 | 0.2392 | 3.4980 |
| 800 | 0.1630 | 3.5379 |

第400步取得最佳验证Loss。之后训练Loss继续下降、验证Loss持续回升，过拟合比上一轮更清楚，因此正式模型选择第400步而不是第800步。

## 同一测试集的公平对比

旧版第300步与平衡版第400步使用同一套v3测试问题、相同Temperature、Top-K、最大长度和逐题随机种子：

| 模型 | 完全正确 | 包含答案 | EOS停止 |
|---|---:|---:|---:|
| 旧分类版最佳模型 | 0/100 | 1/100 | 100/100 |
| 平衡版最佳模型 | 38/100 | 41/100 | 100/100 |

旧模型本来针对另一任务分布训练，因此该表反映它迁移到v3任务的能力，不代表所有场景的绝对模型排名。

## 平衡版分项成绩

| 任务 | 完全正确 |
|---|---:|
| 原文事实问答 | 0/10 |
| 事实答案核验 | 9/15 |
| 概念身份 | 1/15 |
| 明确指令 | 8/25 |
| 日常对话 | 0/15 |
| 诚实回答未知 | 20/20 |

总体38分中20分来自相同模板的未知回答，所以不能只展示总分。事实问答和日常对话仍为0，是当前最重要的失败项。

## 固定10题

旧分类模型常输出“人物、势力、异火”；平衡版不再被单一类别支配，但仍会拼接训练答案片段。例如“今天天气怎么样”生成了与任务拆分有关的混合句，“萧炎现在在哪里”只回答“那里”。完整四模型逐题结果见 `prompt10_balanced_comparison.md`。

## 为什么不继续训练

第400步之后验证Loss连续变差，继续训练只会记住训练样本。当前失败更可能来自：

1. 字符级Token序列效率低，语义单位被拆得太碎。
2. 约710万参数容量有限，难以从少量问法泛化到新意图。
3. 只有100个独立事实主题和50个对话意图，知识与行为覆盖仍小。
4. 预训练目标主要是小说续写，不擅长从问题中提取并组织事实答案。
