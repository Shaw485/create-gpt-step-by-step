## 结论先行

M021 已把“单本小说模型能否问答”拆成两个可证伪问题：

1. **模型是否有容量学习有限小说问答？有。** 高学习率 Canary 在 64 条训练问法和 16 条未见问法 Dev/Selection 上取得严格完整答案 100%/100%。
2. **学会问答后能否保留小说语言？当前配方还没有完全做到。** 高学习率让固定窗口 BPC 退化 43% 以上；加入正式预训练 Train Token 回放后，BPC 退化降到 1.89%–3.05%，但最优 `replay_weight=0.25` 仍有 1/16 小说提示直接输出 EOS。

`replay_weight=0.25` 是当前最优诊断节点：严格完整匹配为 Train 87.50%、Dev/Selection 68.75%；非盲命题级复核为 95.31%/87.50%，关系错误、问答空回答、截断和严重重复均为 0；固定窗口 BPC 仅退化 2.33%。但是它的小说续写只有 15/16 非空，原严格 exact 门也保持失败，因此不是候选，不进入 public、sealed 或发布。

下一阶段的主要矛盾已经从“模型不会问答”变为“任务语义评分与小说续写保持”。正式 A0 将使用结构化命题评分、自然问法和 SFT 格式的原生小说续写，再以 `replay_weight=0.25` 作为回放起点。

## 1. 为什么旧 v7 不能继续训练

## 4. 严格答案与真实语义

Step 400 `0.25` 组有 13 条规范化逐字不一致。独立交叉复核把其中 8 条判为命题等价，例如：

- “萧炎是萧战的儿子”与“萧战是萧炎的父亲”；
- “药尘是药老曾经的名字，二者是同一人物”与“药尘就是药老”。

剩余 5 条是真错误：两条焚决问题串到异火炼药，一条药老原名漏答“药尘”，一条别名问题漏答“药尘”，一条师徒问题串到父子关系。

命题复核后 Train 为 61/64，Dev/Selection 为 14/16；每个 fact 的 Train 最低 7/8、Dev/Selection 最低 1/2。详细逐条证据见 [语义复核](canary_replay_w025_semantic_review.md)。

这项复核查看过参考答案，不是盲审，也不会追溯修改严格 exact gate。它的作用是证明正式 v7.1 必须使用结构化命题、关系方向和任务相关性评分，而不能要求答案逐字相同。

## 5. 已执行的下一步优化

本轮已经完成原计划中的“联合回放”优化，并按单变量方式比较 `replay_weight=0.5/0.25/0.1`：

```text
total_loss = assistant_only_sft_loss
           + replay_weight × pretrain_next_token_loss
```

三组均从纯预训练 Step 5750 独立初始化，Peak LR `1e-5`、Minimum LR `1e-6`、Warmup 20、SFT Batch 8、Replay Batch 4×Block 128、400 步。每条 Canary Train 记录恰好抽取 50 次；每组 replay 400 batches、1600 windows、204800 targets。没有从其他 SFT 权重续训。

结果表明 `0.25` 是当前最有价值的起点：相对 `0.5` 提高问答且清除关系错误，相对 `0.1` 同样严格问答但更好地保留 BPC 与非空续写。没有任何节点通过所有硬门，因此没有权重被标记为候选。

## 6. 后续训练计划

### A0：核心问答、边界与小说保持

1. 重构旧 v7 的 A0 子集，不直接复用 10,000 条旧分布：核心事实 1,920 Train、领域边界 960 Train、SFT 格式原生小说续写 1,040 Train，共 3,920 条。
2. 每个事实冻结结构化命题：实体、关系、方向、时间范围、允许同义表达和禁止冲突；exact 只作诊断。
3. 回答先给结论，去除六种统一开头；加入裸问、自然改写、纠错、逆关系和多轮追问，但语义组不得跨 split。
4. 延续联合目标，以 `replay_weight=0.25` 为中心，仅比较 `0.20/0.25/0.30`；固定 LR、数据、Seed 和 Step，避免多变量混调。
5. 每 125 步先跑结构化核心题、EOS、关系与重复门；问答子门通过后再跑固定窗口 BPC 和 16 条小说续写。任何节点出现 BPC ≥10% 退化或小说续写非空不足 16/16，立即停止。
6. A0 通过后，才依次加入单证据、多证据、真实聊天和摘要/改写任务；每阶段均从 Step 5750 独立初始化，不从上一阶段 SFT 权重累积未知影响。

### RAG：承担模型不应硬记的内容

- 参数内 SFT 只负责核心人物、别名、直接关系和稳定设定。
- 精确章节、首次出现、全书计数、长尾人物与多跳关系交给章节/实体索引。
- 先验证检索 Recall@k，再验证 gold-evidence 生成，最后做端到端；不能用生成器的流畅输出掩盖 retrieval miss。

### 后训练顺序

```text
纯预训练 Step 5750
  → A0 结构化语义 + 续写保持 + replay 0.25 中心消融
  → A1 单证据
  → A2 多证据与抗干扰
  → A3 多轮、EOS 与边界
  → A4 摘要、改写、短续写
  → Public 自动门
  → 独立真人审核
  → 单一冻结候选一次性 Sealed
  → 事实正确后才考虑 DPO/ORPO；当前不做 PPO/RLHF
```
