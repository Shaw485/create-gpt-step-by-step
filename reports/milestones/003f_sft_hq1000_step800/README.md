# M003f：1000条数据的SFT 800步正式实验

## 结论先行

训练流程成功，模型学会了短回答格式和 `<EOS>` 停止，但没有成为可靠问答模型。验证Loss最低点在第300步；继续训练到800步使训练Loss继续下降，却没有改善验证Loss。固定开放问题暴露出明显的“万物皆分类”偏置。

因此本阶段推荐保存第300步模型作为实验最佳模型，但不把它称为最终可用助手。下一轮应调整SFT数据结构，而不是继续增加训练步数。

## 公平实验设置

- 从统一的SFT前检查点重新开始，没有接续20步安全试跑。
- 数据切分：800条训练、100条验证、100条测试。
- Step 800、Batch Size 4，约等于4个epoch。
- 学习率 `1e-4`、Weight Decay `0.01`、梯度裁剪 `1.0`。
- CPU训练、随机种子42；每100步完整评估训练集和验证集。
- 模型参数：7,099,779。
- 模型选择只看验证Loss；选定第300步后，才一次性运行保留测试集。

## Loss结果

| Step | 训练 Loss | 验证 Loss |
|---:|---:|---:|
| 0 | 5.1175 | 5.2546 |
| 100 | 0.8519 | 1.3440 |
| 200 | 0.5734 | 1.2577 |
| 300 | 0.4354 | **1.2351** |
| 400 | 0.2929 | 1.2416 |
| 500 | 0.2271 | 1.2949 |
| 600 | 0.1850 | 1.2711 |
| 700 | 0.1401 | 1.2971 |
| 800 | 0.1295 | 1.2891 |

第300步之后训练Loss继续降低，而验证Loss震荡回升，是轻微过拟合。程序将第300步保存在 `sft_hq1000_step800_best.pt`，第800步另存为最终过程模型，二者没有互相覆盖。

## 保留测试集结果

仅评估第300步最佳模型：

| 指标 | 结果 |
|---|---:|
| 测试样本 | 100 |
| Exact Match | 26/100 |
| 修正后的答案包含 | 26/100 |
| `<EOS>`主动停止 | 100/100 |

按问法拆分后，直接分类7/15、完整类别8/15、多项选择8/15、肯定判断3/15完全正确；解释题、错误类别纠正、体系题和原5道事实题均为0。这说明模型主要学会了部分短分类模板，没有稳健掌握概念关系和事实回答。

## 固定10题观察

SFT前模型主要续写小说；SFT后模型会短答并停止，但对训练分布外的问题经常输出“人物”“势力”“异火”等类别。完整逐题结果见 `prompt10_comparison.md`。这证明格式能力改善，不等于问答能力改善。

## 根因判断

最终1000条虽然标签干净，但900条新增数据都属于概念分类，数量上压倒100条事实问答。模型为了快速降低Loss，学到了“收到问题就输出类别”的捷径。教学实验因此得到一个重要结论：高质量不仅指单条无乱码、标签正确，还必须包括任务比例、问题多样性和目标行为的平衡。

## 下一轮建议

1. 暂停继续训练当前数据，避免强化分类偏置。
2. 保留150个概念，但每个概念最多保留1至2道分类题。
3. 将主要样本改为直接事实回答、关系问答、简短解释、不知道/拒答和一般指令。
4. 建立固定开发集，分别报告事实、分类、解释、开放域和拒答能力。
5. 数据调整后仍从同一个SFT前检查点重新训练，保持可比性。
