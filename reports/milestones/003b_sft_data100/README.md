# M003b：SFT 数据扩充到100条

## 扩充结果

保留原50条数据和固定5道测试题不变，新增50条带原文证据的问答。组合后共有80条训练、15条验证、5条测试数据，共100个互不重复的知识主题。

新增内容重点覆盖修炼等级、炼药条件、魔核用途、魔兽等级、飞行斗技、紫云翼、玄重尺与焰分噬浪尺。每条记录均通过指定原文行证据、字符词表、重复问题、切分数量和跨集合主题泄漏检查。

最终统计为100条记录、100个知识主题，最长序列50个 Token；问题和补齐位置共有1528个屏蔽标签，回答与 `<EOS>` 共有969个监督标签。基础词表仍为4478，加入特殊 Token 后仍为4483，不需要再次修改模型结构。

## 为什么保留固定测试题

5道测试题已经记录了 SFT 前基线。如果更换测试题，就无法进行严格的训练前后对比。因此本次只扩充训练和验证数据，不增加或修改测试问题。

## 下一步

用100条组合数据重新从 SFT 前初始化 checkpoint 开始训练，而不是从40条数据的20步模型继续。这样可以把“数据量增加”作为唯一主要变化，方便比较40条与80条训练数据的 Loss 和泛化差异。
