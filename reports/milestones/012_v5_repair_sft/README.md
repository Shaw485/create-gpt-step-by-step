# M012 v5 定向补强 SFT 数据与100步安全试训

## 结论

M011 的分类型诊断只有 5/30，说明模型虽然开始有聊天形态，但小说人物、小说事实、基础数学、证据判断和能力边界都没有学稳。M012 不继续盲目加 step，而是先按失败类别构造 v5 定向补强数据。

本阶段保留 M011 的 5999 条混合 SFT 数据，再新增 2000 条修复样本，最终形成 7999 条 training-ready 数据。新增样本专门覆盖：已知小说人物不要过度拒答、章节事实锚点、证据片段实体匹配、基础加法、实时信息能力边界、项目概念解释。

100步安全试训已经通过：验证 Loss 从 `6.3811` 降到 `5.1405`，checkpoint、样本生成和30题诊断链路都能运行。随后从同一 M007 预训练 checkpoint 重新启动，正式训练到2000步；验证 Loss 降到 `1.6750`，但30题严格诊断只有 `6/30`。这说明 v5 数据方向有效，但还没有修好核心能力。

## 样本观察

固定样本显示，100步后模型还会重复“萧炎”和“是否”，例如天气题会串到萧炎，数学题会回答“一章”。这说明 v5 数据还没有被充分学习。

这不是失败，而是安全试训的正常结论：数据和脚本通了，但模型行为还没到验收阶段。

### 2000步分类型诊断

最初诊断脚本会把“第3000章的标题是《收场》”误判为通过；本阶段收紧规则，要求第300章标题题必须同时包含“第300章”和“收场”。严格口径下，step2000 latest低温诊断为 `6/30`，EOS 为 `24/30`。

| 类别 | 通过 | 总数 | 准确率 |
|---|---:|---:|---:|
| 小说人物 | 2 | 5 | 40.00% |
| 小说事实 | 1 | 5 | 20.00% |
| 证据判断 | 1 | 5 | 20.00% |
| 能力边界 | 1 | 5 | 20.00% |
| 基础数学 | 0 | 5 | 0.00% |
| 通用聊天 | 1 | 5 | 20.00% |

对比M011的5/30，v5在已知小说实体和局部事实上有轻微改善，但没有解决核心问题。尤其是基础数学仍为0/5，证据实体匹配仍会把“韩枫和紫研”答成“韩枫和韩枫”，能力边界容易把股票、汇率和饭店问题串成天气模板，通用聊天被“不要回答章节号”的负样本污染。

因此，下一步不应直接宣布v5成功，也不建议立刻只加到5000步。更稳的做法是先做一个小修复：减少“不要回答章节号”这类否定模板的比例，增加直接自然聊天答案和更短、更干净的数学答案；然后再决定是否从step2000继续或从M007重新训。

## 下一步

下一步建议先修v5数据，而不是马上冲5000步：

1. 降低“不要回答章节号”负样本比例，避免污染普通聊天；
2. 增加自然鼓励、学习计划、概念解释的正向答案；
3. 把数学答案缩短成稳定模板，例如“答案是5。”；
4. 对证据实体匹配增加更多“第二个人不能复制第一个人”的样本；
5. 修完后重新训练，并继续用30题分类诊断验收。
