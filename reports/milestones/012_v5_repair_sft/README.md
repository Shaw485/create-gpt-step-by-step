# M012 v5 定向补强 SFT 数据与100步安全试训

## 结论

M011 的分类型诊断只有 5/30，说明模型虽然开始有聊天形态，但小说人物、小说事实、基础数学、证据判断和能力边界都没有学稳。M012 不继续盲目加 step，而是先按失败类别构造 v5 定向补强数据。

本阶段保留 M011 的 5999 条混合 SFT 数据，再新增 2000 条修复样本，最终形成 7999 条 training-ready 数据。新增样本专门覆盖：已知小说人物不要过度拒答、章节事实锚点、证据片段实体匹配、基础加法、实时信息能力边界、项目概念解释。

100步安全试训已经通过：验证 Loss 从 `6.3811` 降到 `5.1405`，checkpoint、样本生成和30题诊断链路都能运行。但100步还太短，不能判断 v5 最终效果；当前诊断仍为 5/30，样本也明显不稳定。下一步应从同一 M007 预训练 checkpoint 正式训练到 2000/5000 步，再用同一套30题分类型评估验收。

这个结果不能直接和M011的5000步最终结果比较，因为M012这里只训练了100步。它的意义是确认：分类型评估链路可以复用，后续正式训练必须看同一套指标，而不是只看总Loss。

## 样本观察

固定样本显示，100步后模型还会重复“萧炎”和“是否”，例如天气题会串到萧炎，数学题会回答“一章”。这说明 v5 数据还没有被充分学习。

这不是失败，而是安全试训的正常结论：数据和脚本通了，但模型行为还没到验收阶段。

## 下一步

下一步应在 v5 数据上做正式SFT：

1. 从同一 M007 预训练checkpoint重新启动；
2. 先训练到2000步，每500步保存样本；
3. 用验证Loss选择候选checkpoint；
4. 对候选checkpoint跑30题分类型诊断；
5. 如果小说人物、基础数学、能力边界仍不达标，再继续补数据，而不是只加step。
