# M003h：平衡版 SFT v3 的20步安全试跑

## 目的与配置

从统一的 `sft_stage1_init_pre_sft.pt` 重新开始，用800条平衡版训练数据更新20步；Batch 4、学习率 `1e-4`、Weight Decay `0.01`、梯度裁剪 `1.0`，每5步完整评估800条训练和100条验证。100条测试未参与。

## Loss结果

| Step | 训练Loss | 验证Loss |
|---:|---:|---:|
| 0 | 5.6150 | 6.2076 |
| 5 | 4.5743 | 5.5175 |
| 10 | 3.9050 | 5.0209 |
| 15 | 3.5198 | 4.7367 |
| 20 | 3.2161 | 4.5047 |

训练与验证Loss同时下降，每次验证均刷新最佳检查点。梯度有限，保存与重新加载正常，报告中的测试参与数为0。安全闭环通过后，800步正式实验再次从统一SFT前检查点开始，没有接续本试跑参数。
