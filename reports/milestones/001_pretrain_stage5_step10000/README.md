# M001：Stage 5 字符级预训练基线

## 一句话结论

模型已经学会《斗破苍穹》的小说词汇、对话和动作句式，但面对问题仍会继续写小说，不具备稳定问答和指令遵循能力。

## 视频可用结论

1. Loss 从约8.39下降到约3.09，模型确实学会了小说语言分布。
2. Top-1达到42.71%，说明近一半位置的下一个字符能排在第一名。
3. 输出开始像小说，但所有问题都会被当成小说开头继续写。
4. 这证明“预训练让模型会写”不等于“模型会回答问题”。
5. 下一阶段 SFT 将保持固定问题不变，展示训练目标变化带来的行为变化。
