# M011 v4 混合聊天 SFT 2000步实验

## 结论

M010 的问题很清楚：模型已经学会短答和 EOS 停止，但一遇到非小说问题，仍然很容易输出章节号、人物名和数字模板。M011 因此不继续只喂小说问答，而是在 2999 条小说 SFT 候选之外，加入 3000 条通用聊天、基础算术、项目解释、实时能力边界、学习计划、指令改写、诚实未知和领域切换样本。

本阶段从同一个 M007 预训练 checkpoint 重新启动 SFT。2000 步后，验证 Loss 从 `6.7727` 降到 `1.6600`，模型不再只是小说续写，已经开始学会“像回答问题一样回答”。但它仍不是合格聊天模型：小说事实、数学题和部分概念解释仍会错，说明当前阶段只能判定“聊天格式和拒答边界有所改善”，不能判定“问答质量达标”。

## 为什么要做混合聊天数据

M010 的 SFT 数据几乎都来自小说任务，模型学到的高频模式就是：

- 问题常常和章节有关；
- 答案常常包含“第几章”“证据片段”“萧炎”等表达；
- 即使用户问天气、数学、学习计划，也可能被硬套成小说回答。

M011 加入通用样本，是为了把训练分布从“小说问答”扩成“小说问题 + 普通聊天 + 不知道就说不知道 + 不要把所有问题都当小说”。这不是让 800 万参数模型突然拥有大模型能力，而是先纠正明显的数据偏置。

## 样本观察

固定样本显示了“格式改善”和“能力不足”同时存在：

| 类型 | 输入 | Step 2000输出 | 判断 |

| 非小说/鼓励 | 请写一句鼓励学习的话。 | 先找出卡住的具体点，再回到一个最小例子重新做。 | 基本像聊天回答 |

## 分类型诊断评估

为了避免“总 Loss 下降，但某些能力其实坏掉”的假象，本阶段新增一套公开诊断评估。它只用于教学复盘和回归观察，不消耗隐藏测试集；报告中明确记录 `test_records_consumed: 0`。

第一次评估时规则过松，得到过高的 10/30：例如模型只要输出一个“是”就可能误判通过。随后收紧规则，要求章节题必须命中关键标题，边界题必须匹配问题主题，数学题不能夹带错误数字。收紧后的结果更接近真实体感：总分为 5/30。

| 类别 | 通过 | 总数 | 准确率 | 主要问题 |
|---|---:|---:|---:|---|
| 小说人物 | 0 | 5 | 0.00% | 对萧炎、药尘、药老、异火过度拒答 |
| 小说事实 | 0 | 5 | 0.00% | 章节标题、说话人和是否题不可靠 |
| 证据判断 | 1 | 5 | 20.00% | 能套“证据片段”格式，但实体匹配会错 |
| 能力边界 | 1 | 5 | 20.00% | 天气题可用，新闻、股票、汇率、附近饭店会串题 |
| 基础数学 | 0 | 5 | 0.00% | 会生成数字格式，但答案几乎不可靠 |
| 通用聊天 | 3 | 5 | 60.00% | 鼓励、学习安排较好，概念解释会串到其他知识 |

完整报告见 `category_eval_step5000_latest_lowtemp.md` 和 `category_eval_step5000_latest_lowtemp.json`。

这个结果说明，M011 已经把模型从“只会小说续写/章节模板”推进到“能部分聊天和停止”，但还没有形成可靠问答。下一步不应该继续盲目加 step，而应该按失败类别补数据：小说已知人物正例、章节事实、证据实体匹配、基础数学、不同实时问题的边界回答，以及减少“已知也说不知道”的过度拒答模式。

## 判断

- 混合聊天数据有效缓解了“全是章节号和数字”的偏置。
- 验证 Loss 明显下降，说明模型正在学习 SFT 目标。
- EOS 停止基本可用，输出长度能被约束。
- 通用聊天语气开始出现，但数学、事实、概念解释仍不可靠。
- 继续到5000步后，通用边界类回答更像样，但小说问题出现过度拒答，说明数据分布和能力仍未平衡。
- 分类型诊断显示总分只有5/30，基础数学、小说人物和小说事实均为0/5；这比总Loss更直接地暴露当前SFT数据的短板。
- 当前不应发布为“会聊天的模型”，只能作为“从小说续写转向指令回答”的中间里程碑。

## 下一步

下一步建议不要只盲目增加步数，而是两条线并行推进：

1. 暂停盲目加步数，先补强更高质量的通用聊天与基础推理数据，尤其是数学、概念解释、真实问答、小说人物介绍和“知道/不知道”的边界。
2. 增加分类型评估：小说事实、小说人物、证据判断、通用聊天、基础数学、能力边界分别计分，避免总Loss掩盖某一类退化。
3. 数据改好后，再从同一M007预训练checkpoint重新SFT，并保留同样的3500/5000对照。

如果 5000 步后验证 Loss 继续下降，但样本仍明显错，就说明主要瓶颈不是训练步数，而是模型容量和数据质量。
