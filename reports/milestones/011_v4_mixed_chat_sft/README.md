# M011 v4 混合聊天 SFT 2000步实验

## 结论

M010 的问题很清楚：模型已经学会短答和 EOS 停止，但一遇到非小说问题，仍然很容易输出章节号、人物名和数字模板。M011 因此不继续只喂小说问答，而是在 2999 条小说 SFT 候选之外，加入 3000 条通用聊天、基础算术、项目解释、实时能力边界、学习计划、指令改写、诚实未知和领域切换样本。

本阶段从同一个 M007 预训练 checkpoint 重新启动 SFT。2000 步后，验证 Loss 从 `6.7727` 降到 `1.6600`，模型不再只是小说续写，已经开始学会“像回答问题一样回答”。但它仍不是合格聊天模型：小说事实、数学题和部分概念解释仍会错，说明当前阶段只能判定“聊天格式和拒答边界有所改善”，不能判定“问答质量达标”。

## 为什么要做混合聊天数据

M010 的 SFT 数据几乎都来自小说任务，模型学到的高频模式就是：

- 问题常常和章节有关；
- 答案常常包含“第几章”“证据片段”“萧炎”等表达；
- 即使用户问天气、数学、学习计划，也可能被硬套成小说回答。

M011 加入通用样本，是为了把训练分布从“小说问答”扩成“小说问题 + 普通聊天 + 不知道就说不知道 + 不要把所有问题都当小说”。这不是让 800 万参数模型突然拥有大模型能力，而是先纠正明显的数据偏置。

## 样本观察

固定样本显示了“格式改善”和“能力不足”同时存在：

| 类型 | 输入 | Step 2000输出 | 判断 |
|---|---|---|---|
| 非小说/天气 | 今天天气怎么样？ | 我不能直接帮你实时天气。你给我城市和学习，我可以帮我城市和参数据。 | 不再硬答章节，但句子仍不稳 |
| 非小说/鼓励 | 请写一句鼓励学习的话。 | 先找出卡住的具体点，再回到一个最小例子重新做。 | 基本像聊天回答 |
| 非小说/数学 | 一加一等于几？ | 验加0等于6。 | 未学会可靠算术 |
| 非小说/未知 | 玄风石碑是谁？ | 现有资料不足，无法确定。 | 拒答边界明显改善 |
| 小说/事实 | 第159章中说出“准备突破吧。这是你的机缘。万”这句话的是谁？ | 是药老说的。 | 局部成功 |
| 小说/人物 | 药尘是谁？ | 我是一个本地2PTossssss，我再足够可靠的信息。 | 仍明显失败 |

完整小说/非小说样本见 `novel_vs_general_step2000_samples.md`，训练中固定监控样本见 `sft_v4_mixed_chat_step2000_report.json`。

## 判断

- 混合聊天数据有效缓解了“全是章节号和数字”的偏置。
- 验证 Loss 明显下降，说明模型正在学习 SFT 目标。
- EOS 停止基本可用，输出长度能被约束。
- 通用聊天语气开始出现，但数学、事实、概念解释仍不可靠。
- 当前不应发布为“会聊天的模型”，只能作为“从小说续写转向指令回答”的中间里程碑。

## 下一步

下一步建议不要只盲目增加步数，而是两条线并行推进：

1. 保持 M011 数据，继续训练到 5000 步，每 500 步保存固定小说/非小说样本，观察验证 Loss 是否继续下降。
2. 追加更高质量的通用聊天与基础推理数据，尤其补强数学、概念解释、真实问答和“不要把普通问题当小说”的负样本。

如果 5000 步后验证 Loss 继续下降，但样本仍明显错，就说明主要瓶颈不是训练步数，而是模型容量和数据质量。
